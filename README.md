# my sketchbook

1. Unzip and open the `my-sketchbook` folder in VS Code, then open `index.html` in Chrome.
2. Add a sketch: copy the image into `images/`, then add one line to the `sketches` list at the top of `script.js`:
   { file: "my-drawing.jpg", title: "My drawing" },
3. Remove a sketch: delete its line in `script.js`.
4. Edit the About text and profile picture in index.html.
5. Change colors and fonts in :root at the top of style.css.
